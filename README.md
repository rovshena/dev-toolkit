# Dev Toolkit

The hardware, apps, and tools I use every day as a PHP/Laravel developer on macOS.

## Hardware

- **[MacBook Pro 16" (M4 Pro)](https://www.apple.com/macbook-pro/)** — Fast, silent, and the Liquid Retina XDR display is great for long coding sessions.

## Editors & IDEs

- **[PhpStorm](https://www.jetbrains.com/phpstorm/)** — My main IDE. Excellent PHP and Laravel support, refactoring, and debugging out of the box.
- **[JetBrains Toolbox](https://www.jetbrains.com/toolbox-app/)** — Keeps PhpStorm installed and up to date.
- **[Visual Studio Code](https://code.visualstudio.com/)** — For quick edits, config files, and anything outside PHP.

## AI

- **[Claude Code](https://claude.com/claude-code)** — AI pair programmer in the terminal and in PhpStorm.
- **[Claude](https://claude.ai/download)** — Desktop app for research, writing, and thinking through problems.

## Terminal & CLI

- **[Warp](https://www.warp.dev/)** — Modern terminal with blocks, completions, and good defaults. Runs zsh.
- **[Homebrew](https://brew.sh/)** — Package manager for everything below.
- **[Git](https://git-scm.com/)** and **[GitHub CLI](https://cli.github.com/)** — Version control and PRs from the terminal.

## Languages & Runtimes

- **[PHP](https://www.php.net/)** and **[Composer](https://getcomposer.org/)** — Installed via Homebrew.
- **[Laravel Installer](https://laravel.com/docs/installation)** — Spin up new Laravel projects.
- **[nvm](https://github.com/nvm-sh/nvm)** — Manages Node.js versions for front-end tooling.

## Databases & Containers

- **[MySQL](https://www.mysql.com/)** and **[PostgreSQL](https://www.postgresql.org/)** — Local databases via Homebrew.
- **[TablePlus](https://tableplus.com/)** — Clean, fast GUI for working with databases.
- **[OrbStack](https://orbstack.dev/)** — Lightweight Docker and Linux VMs, much faster than Docker Desktop on Apple Silicon.

## Browsers

- **[Google Chrome](https://www.google.com/chrome/)** — Main browser and DevTools.
- **[Firefox](https://www.firefox.com/)** — Cross-browser testing; great CSS Grid and Flexbox inspectors.
- **[Safari](https://www.apple.com/safari/)** — Testing WebKit behavior.

## Team & Productivity

- **[Linear](https://linear.app/)** — Issue tracking and planning with cycles.
- **[Grammarly](https://www.grammarly.com/)** — Catches typos and tightens up emails and docs.
